# Fontes em PDF

Forneça as leituras ou indique onde estão. O agente organiza os PDFs aqui, extrai o texto, faz OCR quando necessário e atualiza o corpus. Você não precisa executar comandos.

Agente: siga o procedimento de preparação e extração do [AGENTS.md](../AGENTS.md). Preserve os originais e registre problemas de extração no índice.

As [leituras da oficina](../atividades/01-mapa-de-evidencias.md) têm links externos para os PDFs nas revistas. O agente baixa quando necessário. PDFs de terceiros e suas extrações integrais permanecem locais e não entram no repositório público.

O texto nativo é preservado. Se houver dúvida, o OCR fica como alternativa para o agente comparar com o PDF. Orientação e escolha da versão exigem essa conferência; o autor não precisa resolver parâmetros técnicos.
